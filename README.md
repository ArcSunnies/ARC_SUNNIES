# ArcSunnies ($ASN) Website Package

A responsive, static landing page for **ArcSunnies**, a community-first meme project. It uses only the project details and official social links supplied for this website.

## Files
- `index.html` — complete responsive website, styles, roadmap, and project disclaimer
- `assets/sunnies-logo.png` — Sunnies logo artwork
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing
- `ROADMAP.md` — editable roadmap copy
- `DISCLAIMER.md` — project risk disclaimer

## Before publishing
1. Add only official social links you control.
2. Confirm the chain, contract address, token supply, token mechanics, and launch status before adding them to the site.
3. Keep NFT and staking sections labelled **Coming soon** until the products are actually available and reviewed.
4. Do not add fake audit badges, exchange listings, partnerships, or guaranteed returns.

## Publish with GitHub Pages
1. Create a public GitHub repository named `ArcSunnies`.
2. Upload the contents of this folder to the repository root (not the ZIP itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment to finish, then open the URL shown in Settings → Pages.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Customize
Open `index.html` and replace the community placeholder with your verified official social links once you have them. This site is static and does not connect wallets, collect user data, or provide token purchasing/staking functionality.
